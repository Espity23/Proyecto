# Proyecto-estructura-de-datos--FoodFlow
Sistema de gestión de pedidos de restaurante desarrollado en Java

Descripción

FoodFlow es un sistema de gestión de pedidos de restaurante desarrollado en Java. Permite crear pedidos con varios productos, calcular sus subtotales y totales, consultar pedidos pendientes, atenderlos en orden de llegada y eliminar el último pedido agregado cuando todavía está pendiente.

Sistemas utilizados para la creacion del proyecto

- Java
- JDK 21
- Visual Studio Code

Estructuras de datos

- ArrayList: almacena los detalles de productos que componen cada pedido.
- Queue: administra los pedidos pendientes siguiendo el principio FIFO.
- Stack: permite identificar el último pedido agregado siguiendo el principio LIFO.

Requisitos

- Tener instalado Java JDK 21 o una versión compatible.
- Contar con los archivos fuente del proyecto.

Cómo ejecutar el programa

1. Abre una terminal en la carpeta que contiene los archivos ".java".

2. Compila el proyecto:
   
   "javac Hola.java Producto.java DetallePedido.java Pedido.java Restaurante.java"

3. Ejecuta la aplicación:
   
   "java Hola"
